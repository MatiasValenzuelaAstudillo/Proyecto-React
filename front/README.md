# HuertoHogar — versión React

Migración del proyecto original HTML/CSS/JavaScript vanilla a una aplicación React con Vite.

## Ejecutar

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
npm run preview
```

## Funcionalidades

- Navegación SPA con React Router.
- Catálogo con filtros por categoría.
- Carrito persistido en `localStorage`, con control de cantidades y stock.
- Vistas de inicio, productos, carrito, nosotros, login, registro y perfil.
- Recursos visuales originales conservados en `public/assets/img`.
